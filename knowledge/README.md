# 模拟平台知识库

200条平台政策（20类，每类10条），200件商品（前50件含订单中的10件商品及40件相近款，后150件含15类其他商品，每类10款）。全部参数和规则均为虚构，不代表真实商家。

修改资料后停止应用，运行 `python -m scripts.ingest_knowledge --root knowledge`，完成后重启。首次运行下载多语言E5 Small，需联网；还需启动本地Qdrant。仅删除数据库不会自动重新生成向量，需重新导入。

清单示例与导入替换语义见[README第8.5节](../README.md#85-导入你自己的外部知识资料)，模型缓存与数据位置见第10.1节。五组长对话见[多轮验收脚本](../docs/usage_and_scenarios.md)及前端同名标签页。
